# Plague’s Book Reader Wiki

A documentation-first public project for local read-aloud assistance. Application source and turnkey installation remain pending provenance/licensing and clean-system runtime verification. This is not a full desktop screen reader.

- [Setup](Setup.md) — status, portable configuration and verification plan
- [Engines and models](Engines-and-models.md) — actual modes, observed versions and model artifacts
- [Voices](Voices.md) — owner-authorized Sabrina reference and user-supplied voices
- [Using Reader](Using-Reader.md) — first use, import, preparation, playback and bookmarks
- [Troubleshooting](Troubleshooting.md) — missing runtime/audio, formatting, resume and quality
- [Release decisions](Release-decisions.md) — remaining source, dependency and distribution gates

Project repository: https://github.com/kaotickj/plagues-book-reader
